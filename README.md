## Hi, I'm s4njk4n

I build free, open-source tools for the [XDC Network](https://xdc.org) and publish them at **[xdcoutpost.xyz](https://xdcoutpost.xyz)**.

Most of them started with a gap I noticed in the ecosystem: something people kept asking for, or a job that was harder than it needed to be. I build the fix, tidy it up and share it. Everything here is free to use, MIT licensed, and built so you can run it yourself without handing your keys or data to anyone.

### For node and masternode operators

- **[XDC Sentinel](https://github.com/s4njk4n/XDC_Sentinel)**: phone alerts when an XDC node goes offline, plus a daily all-clear when it's fine
- **[XDC Tycoon](https://github.com/s4njk4n/XDC_Tycoon)**: alerts when your masternode's status changes or a reward payment lands
- **[XDC Epoch Notifier](https://xdcoutpost.xyz/XDC_Epoch_Notifier/)**: a daily report of what each masternode earned, and a loud alert if one earned nothing
- **[Masternode Rewards Calculator](https://xdcoutpost.xyz/XDC_Masternode_Rewards_Calculator/)**: total a masternode's epoch rewards for any period, with CSV export for tax time
- **[Plugin XDC Secure RPC & WSS](https://github.com/s4njk4n/Plugin-XDC-Secure-RPC-WSS)**: set up a hardened XDC node with private RPC and WebSocket access limited to your own IPs

The monitoring tools run free on GitHub Actions, so you don't need a server and there's nothing to pay for.

### For everyday XDC use

- **[XDC PQOnchain](https://xdcoutpost.xyz/XDC_PQOnchain/)**: send post-quantum encrypted messages on-chain, with keys that never leave your browser
- **[XDC Proof](https://xdcoutpost.xyz/XDC_Proof/)**: turn a transaction hash into a clean PDF receipt, with your own branding if you want it
- **[XDC Send Offline Helper](https://xdcoutpost.xyz/XDC_Send_Offline_Helper/)**: prepare transactions for an offline wallet and broadcast them once they're signed
- **[XDC ShopBot](https://github.com/s4njk4n/XDC_ShopBot)**: a Telegram shop that sells digital products for XDC and delivers them automatically ([try the demo](https://t.me/xdcshopbot))
- **[XDC FuelSharp NSW](https://xdcoutpost.xyz/XDC_FuelSharpNSW/)**: cheapest fuel near you in NSW, with your discounts applied and prices in AUDD, XDC or USDC

Also worth a look: **[XDC Library](https://github.com/s4njk4n/XDCLibrary)**, a reading list on XDC that I keep curated. Next up is **XDC FieldMedic**, a bot that spots a struggling RPC endpoint and fixes it before you notice.
